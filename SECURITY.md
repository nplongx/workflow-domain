# Security Policy

## Scope

`workflow-domain` validates and transforms in-memory domain values. It does not authenticate users, verify signatures, authorize actions, store secrets, execute commands, or provide an operating-system sandbox.

Do not treat a valid hash, policy value, approval record, evidence reference, or compiled plan as proof of trusted origin or permission to execute.

## Reporting

Report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository when available. Do not publish exploit details, credentials, private artifacts, or sensitive host data in a public issue. Include affected version, minimal reproduction, expected behavior, and observed behavior.

## Support status

This is an initial `0.1.x` extraction. No production security certification or guaranteed response SLA is claimed.
